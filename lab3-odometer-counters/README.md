# COE 528 Lab 3 – Odometer with Linked Digit Counters

**Course:** COE 528 – Object-Oriented Engineering Analysis and Design  
**Tools:** Java, Maven (NetBeans)

## Overview

Inheritance and abstract classes: an `AbstractCounter` / `Counter` hierarchy with a `DigitCounter` and a `LinkedDigitCounter` that carries into the next digit. The counters are chained into an `Odometer`, and `OdometerDrive` runs it.

## Build / run

```bash
mvn compile
```
Or open the folder as a Maven project in NetBeans / IntelliJ.
