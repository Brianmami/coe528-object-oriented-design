# COE 528 Lab 2 – Procedural Abstraction (Specifications)

**Course:** COE 528 – Object-Oriented Engineering Analysis and Design  
**Tools:** Java, Maven (NetBeans)

## Overview

Practice writing REQUIRES / MODIFIES / EFFECTS specifications:

- `ex1/Ex1.txt` – specification and code for `substituteMax(int[] a, int[] b)`
- `ex2/` – `Palindrome` checker
- `ex3/` – `AnagramChecker`

## Build / run

Each of `ex2/` and `ex3/` is its own Maven project:

```bash
cd ex2 && mvn compile
```
