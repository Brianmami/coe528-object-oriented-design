# COE 528 Lab 4 – Data Abstraction: Stack of Distinct Strings

**Course:** COE 528 – Object-Oriented Engineering Analysis and Design  
**Tools:** Java, Maven (NetBeans)

## Overview

Abstract data types with an overview, abstraction function and rep invariant:

- `StackOfDistinctStrings` – a bounded LIFO stack that rejects duplicates, with `repOK()` and `toString()`
- `Ex2/ADT` – a generic bounded FIFO collection, with `Main` as a driver

## Build / run

```bash
mvn compile
```
Or open the folder as a Maven project in NetBeans / IntelliJ.
