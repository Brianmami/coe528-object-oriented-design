# COE 528 Lab 1 – Flight Booking System

**Course:** COE 528 – Object-Oriented Engineering Analysis and Design  
**Tools:** Java, Maven, JUnit (NetBeans)

## Overview

Object-oriented flight booking model: `Flight`, `Ticket`, `Passenger` (abstract) with `Member` / `NonMember` subclasses that apply different discounts, and a `Manager` that creates flights and books tickets. `FlightTest` contains JUnit tests for the `Flight` class.

## Build / run

```bash
mvn compile
```
Or open the folder as a Maven project in NetBeans / IntelliJ.

```bash
mvn test
```
